Guhan is mostly mouse-driven. These are the shortcuts that exist today. `Cmd` is for macOS; use `Ctrl` on Windows and Linux.

## Inbox

Shortcuts work when your cursor isn't in a text field.

| Shortcut | Action |
|---|---|
| `j` | Select the next conversation |
| `k` | Select the previous conversation |
| `a` | Approve the draft on the selected conversation |
| `t` | Take over the selected conversation |
| `/` | Jump to search |
| `Cmd + Enter` | Send the reply you're writing, or approve and send a draft |

## Sequence editor

Open a Campaign and edit its sequence. Shortcuts work when you're not typing in a field.

| Shortcut | Action |
|---|---|
| `Cmd + Z` | Undo |
| `Cmd + Shift + Z` or `Ctrl + Y` | Redo |

## Prospects

| Shortcut | Action |
|---|---|
| `Left` / `Right` arrow | Scroll the table sideways |
| `Shift + Left` / `Right` | Scroll further |

## Anywhere

| Shortcut | Action |
|---|---|
| `Cmd + Shift + O` | Open Past chats (your Ask Guhan history) |
