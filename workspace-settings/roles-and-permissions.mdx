---
title: Roles and permissions
description: The four built-in roles, what each can do, how invites work, and how licenses relate to seats.
---

A role decides what a teammate can see and change. Guhan has four built-in roles, and org admins can create custom roles from a set of individual permissions.

## The four roles

| Capability | Workspace Admin | Campaign Manager | Sales Rep | Viewer |
|---|:---:|:---:|:---:|:---:|
| View campaigns, sequences, Lists, companies, products, templates | Yes | Yes | Yes | Yes |
| Create and edit campaigns and sequences | Yes | Yes | No | No |
| Launch and publish campaigns | Yes | Yes | No | No |
| Delete campaigns | Yes | No | No | No |
| Create and edit Lists | Yes | Yes | No | No |
| Edit companies, block a company | Yes | Yes | No | No |
| Delete companies | Yes | No | No | No |
| Create and edit products and templates | Yes | Yes | No | No |
| View sender accounts | Yes | Yes | Yes | Yes |
| Connect, disconnect, and share sender accounts | Yes | No | No | No |
| Change a sender account's owner | Yes | No | No | No |
| View calendars and Meetings | Yes | Yes | Yes | Yes |
| Connect your own calendar | Yes | No | Yes | No |
| See all conversations | Yes | Yes | No (own only) | Yes |
| Send messages and replies | Yes | Yes | Yes | No |
| Reassign conversations | Yes | Yes | No | No |
| View analytics | Yes | Yes | Yes | Yes |
| View the Do-Not-Contact list | Yes | Yes | Yes | Yes |
| Add or remove Do-Not-Contact entries | Yes | Yes | No | No |
| Invite, remove, and change members | Yes | No | No | No |
| Edit workspace settings, delete the workspace | Yes | No | No | No |

Billing and organization actions, such as plan changes, credit packs, and creating workspaces, are limited to **org admins**.

## Sales Rep scope

A Sales Rep sees only the conversations assigned to them. They can reply and book meetings within that scope, which keeps a team of reps from stepping on each other.

## Seats and licenses

**One license is one seat.** The number of members in your workspace can't exceed the number of licenses. When you've used them all, the invite form tells you to add another license first. See [Plans and credits](/workspace-settings/plans-and-credits).

## Invite a teammate

<Steps>
  <Step title="Open the Team page">
    Go to **Settings → Team**.
  </Step>
  <Step title="Send the invite">
    Enter their email and pick a role. They receive an email with a link.
  </Step>
  <Step title="They accept">
    The link works for 7 days. You can revoke a pending invite at any time, which invalidates it immediately.
  </Step>
</Steps>

## Change a role or remove a member

On **Settings → Team**, change a member's role or remove them. Data they created, such as Lists and sequences, stays in the workspace.

## Custom roles

Org admins can create custom roles from the Team page by choosing individual permissions. Built-in roles can't be edited, only used as they are. A role that's still assigned to members can't be deleted.

## Sender account ownership

Every sender account has an owner, the person whose LinkedIn, email, or WhatsApp it is. Conversations on that sender are assigned to the owner, and messages go out under their name. Admins can reassign ownership.

## If something's off

- **Can't invite anyone.** You're out of seats. Add a license under Billing.
- **A teammate can't see a conversation.** Sales Reps see only conversations assigned to them. Reassign it or change their role.
- **A teammate can't see a Settings row.** Several rows are for admins only. See [Workspace settings](/workspace-settings/overview).
